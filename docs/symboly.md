# Symboly

Přehled značek používaných na této wiki. Každý řádek odkazuje na stránku s vysvětlením.
{ .lead }

## Množiny

| Symbol | Význam | Čte se | Stránka |
|---|---|---|---|
| $\{1, 2, 3\}$ | množina zadaná výčtem | „množina prvků 1, 2, 3" | [Zápis množin](mnoziny/zapis-mnozin.md) |
| $\{x \in A ;\ V(x)\}$ | množina zadaná vlastností | „množina všech x z A, pro která platí…" | [Zápis množin](mnoziny/zapis-mnozin.md) |
| $x \in A$ | $x$ je prvkem $A$ | „x náleží do A" | [Množina](mnoziny/mnozina.md) |
| $x \notin A$ | $x$ není prvkem $A$ | „x nenáleží do A" | [Množina](mnoziny/mnozina.md) |
| $\emptyset$ | prázdná množina | „prázdná množina" | [Prázdná množina](mnoziny/prazdna-mnozina.md) |
| $A \subseteq B$ | $A$ je podmnožinou $B$ | „A je podmnožinou B" | [Podmnožina](mnoziny/podmnozina.md) |
| $A \subsetneq B$ | vlastní podmnožina | „A je vlastní podmnožinou B" | [Podmnožina](mnoziny/podmnozina.md) |
| $\mathcal{P}(A)$ | potenční množina | „potenční množina A" | [Potenční množina](mnoziny/potencni-mnozina.md) |
| $A \cup B$ | sjednocení | „A sjednoceno s B" | [Sjednocení](mnoziny/sjednoceni.md) |
| $A \cap B$ | průnik | „průnik A a B" | [Průnik](mnoziny/prunik.md) |
| $A \setminus B$ | rozdíl | „A bez B" | [Rozdíl](mnoziny/rozdil.md) |
| $A'$ | doplněk | „doplněk A" | [Doplněk](mnoziny/doplnek.md) |
| $A \mathbin{\Delta} B$ | symetrická diference | „symetrická diference A a B" | [Symetrická diference](mnoziny/symetricka-diference.md) |
| $A \times B$ | kartézský součin | „A krát B" | [Kartézský součin](mnoziny/kartezsky-soucin.md) |
| $(a, b)$ | uspořádaná dvojice | „dvojice a, b" | [Kartézský součin](mnoziny/kartezsky-soucin.md) |
| $\lvert A \rvert$ | mohutnost (počet prvků) | „mohutnost A" | [Mohutnost](mnoziny/mohutnost.md) |
| $\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{C}$ | číselné množiny | „en, zet, kvé, er, cé" | [Číselné množiny](mnoziny/ciselne-mnoziny.md) |
| $\langle a; b \rangle,\ (a; b)$ | uzavřený / otevřený interval | „uzavřený interval od a do b" | [Intervaly](mnoziny/intervaly.md) |

## Dělitelnost

| Symbol | Význam | Čte se | Stránka |
|---|---|---|---|
| $a \mid b$ | $a$ dělí $b$ | „a dělí b" | [Dělitel a násobek](delitelnost/delitel-a-nasobek.md) |
| $a \nmid b$ | $a$ nedělí $b$ | „a nedělí b" | [Dělitel a násobek](delitelnost/delitel-a-nasobek.md) |
| $\mathcal{D}_a$ | množina dělitelů $a$ | „dělitelé a" | [Dělitel a násobek](delitelnost/delitel-a-nasobek.md) |
| $\mathcal{N}_a$ | množina násobků $a$ | „násobky a" | [Dělitel a násobek](delitelnost/delitel-a-nasobek.md) |
| $D(a, b)$ | největší společný dělitel (gcd) | „dé a, b" | [NSD](delitelnost/nsd.md) |
| $n(a, b)$ | nejmenší společný násobek (lcm) | „en a, b" | [nsn](delitelnost/nsn.md) |

## Logika

| Symbol | Význam | Čte se |
|---|---|---|
| $\land$ | a zároveň (konjunkce) | „a" |
| $\lor$ | nebo (disjunkce, nevylučovací) | „nebo" |
| $\lnot$ | negace | „není pravda, že" |
| $\Rightarrow$ | implikace | „jestliže…, pak…" |
| $\Leftrightarrow$ | ekvivalence | „právě tehdy, když" |
| $\forall$ | obecný kvantifikátor | „pro všechna" |
| $\exists$ | existenční kvantifikátor | „existuje" |
