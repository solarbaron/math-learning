## Logika

| Symbol | Význam | Čte se |
|---|---|---|
| $\land$ | a zároveň (konjunkce) | „a" |
| $\lor$ | nebo (disjunkce, nevylučovací) | „nebo" |
| $\lnot$ | negace | „není pravda, že" |
| $\Rightarrow$ | implikace | „jestliže…, pak…" |
| $\Leftrightarrow$ | ekvivalence | „právě tehdy, když" |
| $\forall$ | obecný kvantifikátor | „pro všechna" |
| $\exists$ | existenční kvantifikátor | „existuje" |
